# 𝒵𝒴𝐿𝒪

Форк Telegram для Android (GPLv2) с новым названием и круглой иконкой.

## Как получить APK
1. Загрузи этот репозиторий на GitHub.
2. Получи свои `api_id` и `api_hash` на https://my.telegram.org
3. Repo → Settings → Secrets → Actions: добавь `TG_API_ID` и `TG_API_HASH`.
4. Actions → Build ZYLO → Run workflow → скачай APK из Artifacts.

Локально: `./apply_zylo.sh`, затем открой папку `Telegram` в Android Studio.

Лицензия: GPLv2 — исходники форка должны быть открытыми.
Это неофициальный клиент, не связан с Telegram.
